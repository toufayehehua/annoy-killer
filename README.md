# 扰人杀手 / Annoy Killer

隐藏网页上让你分心的内容。刷新后仍会隐藏，需要时也能恢复。支持 Chrome 和 Microsoft Edge。

## 安装

当前版本为 **1.2.3**。下载对应浏览器的 ZIP，解压到一个固定位置：

| 浏览器 | 下载 | 扩展管理页面 |
| --- | --- | --- |
| Chrome | [Chrome 安装包](chrome/dist/annoy-killer-chrome-1.2.3.zip) | `chrome://extensions` |
| Microsoft Edge | [Edge 安装包](edge/dist/annoy-killer-edge-1.2.3.zip) | `edge://extensions` |

打开对应的扩展管理页面，开启「开发者模式」，加载解压后的文件夹。安装后保留这个文件夹。

如果下载了整个项目，Chrome 加载 `chrome/`，Edge 加载 `edge/`。

## 使用

1. 在普通网页点击工具栏中的插件图标。
2. 移动鼠标选中不想看的内容，点击隐藏。
3. 点击「完成」，或按 `Enter`、`Esc` 保存并退出。

想恢复某项内容时，再打开插件，点击「显示」，然后点击要恢复的项目。

默认选择较大区域。按住 `Shift` 可以缩小选择范围，按住 `Alt`（Mac 为 `Option`）可以进一步缩小。操作中按住 `Ctrl`（Mac 为 `Command`），可以临时正常点击网页。

双击 `Control`（Mac 默认 `Command`）可打开或关闭插件。右键点击插件图标 →「选项」，可以修改双击按键。快捷键需要先让网页获得焦点；设为字母、数字或空格时，在输入框中不会触发。

## 多设备同步

默认使用当前浏览器的账号同步隐藏设置。其他设备需要登录同一个 Google 或 Microsoft 账号，开启浏览器的扩展同步，并安装同一商店版本。Chrome 与 Edge 之间不互通。

可在「选项」中关闭「同步屏蔽规则」，关闭后本机已隐藏的内容仍会保留。同步数量受浏览器限制，内容较多时优先同步最近的设置；同步失败不会清除本机设置。

## 适用范围

部分隐藏设置会在同一网站的其他页面继续生效。网页内容变化后，可能需要重新选择隐藏。浏览器内置页面和扩展商店页面不支持使用。

界面支持简体中文、繁体中文、英语、日语、韩语、德语、法语、西班牙语和巴西葡萄牙语，跟随浏览器语言，其他语言使用英语。
