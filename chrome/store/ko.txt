Annoy Killer로 웹페이지의 방해 요소를 숨기고 읽고 싶은 내용에 집중하세요. 불필요한 배너, 팝업, 사이드바 또는 다른 영역을 직접 선택하여 숨길 수 있습니다.

주요 기능
• 일반 웹페이지에서 확장 프로그램 아이콘을 클릭하고, 페이지 영역에 마우스를 올린 뒤 클릭하여 숨기세요.
• “표시”를 클릭하면 숨긴 항목을 미리 볼 수 있습니다. 숨긴 항목의 아무 곳이나 클릭하면 복원됩니다.
• “초기화”로 페이지의 원래 상태를 미리 보고, “복원”으로 이전의 숨김 상태로 돌아갈 수 있습니다.
• “완료”를 클릭하거나 Enter 키를 눌러 저장하세요. 새로고침 후에도 숨김 규칙이 적용됩니다.

숨김 규칙은 기기에 저장되며, 같은 Google 계정을 사용하고 Chrome 동기화를 켠 기기 간에 Chrome Sync로 기본 동기화됩니다. 옵션에서 규칙 동기화를 끌 수 있으며 단축키 설정은 기기에만 저장됩니다. 별도의 확장 프로그램 계정이나 분석 및 광고 추적은 없습니다. 사라지는 애니메이션을 위한 임시 페이지 캡처는 기기에서만 처리되며 업로드되지 않습니다.

직접 요소를 숨기는 도구이며 네트워크 광고 차단기가 아닙니다. 모든 광고를 차단하거나 유료 콘텐츠 제한을 우회하지 않습니다. 사이트가 변경되면 규칙을 다시 설정해야 할 수 있습니다. Chrome 내부 페이지와 Chrome 웹 스토어에서는 사용할 수 없습니다.

Chrome 언어를 자동으로 따르며 지원되지 않는 언어는 영어로 표시됩니다. 영어, 중국어 간체 및 번체, 일본어, 한국어, 독일어, 프랑스어, 스페인어, 브라질 포르투갈어를 지원합니다.
